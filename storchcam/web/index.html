Gaming-Hilfsdienst fehlt StorchCam bekommt aus Sicherheitsgründen keinen direkten Zugriff auf Docker. Ein kleiner Dienst auf dem Pi übernimmt nur die Gaming-Aufgaben. Er wird einmal im Terminal des Pi eingerichtet:

          
  1. Per SSH am Pi anmelden.
  2. Den Befehl oben ausführen; er fragt nach dem sudo-Passwort.
  3. Danach hier „Erneut prüfen“ tippen.

          
          

        


        

          
Docker ist nicht erreichbar
            
            Ohne Docker lässt sich Gaming nicht installieren. Auf dem Pi prüfen: systemctl status docker. Fehlt Docker ganz, zuerst Docker installieren.
